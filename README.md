# 无限协议 v0.4.1

一款手机竖屏优先、同时兼容电脑浏览器的数字卡牌原型。

在线试玩：<https://flowerbud0.github.io/infinite-protocol/>

## v0.4.1 成长重构

- 基础校准、融合校准和数据提纯改为递减收益的软上限，不再因点满而失去资源用途。
- 新增核心深度的算力与归档两项弱无限升级，成本指数增长。
- 新增同步、序列和融合三条核心专精，专精点来自核心迭代与最高层级，并可免费重置。
- 科技矩阵从总计19级扩展为四条各20级，总计80级，每5级获得里程碑效果。
- 总科技达到60级后开放三项前沿研究，以平方根递减效果提供近似无限的研究数据消耗渠道。
- v0.4及更早存档自动迁移；已有科技、最高层级和核心迭代记录全部保留。

## v0.4 更新

- 新增离线研究收益，基础上限 8 小时，可通过科技延长。

- 新增每日行动清单，随正常出牌、超频、远征和研究进度自动完成。
- 新增协议档案、探索图鉴、长期统计和六项可领取成就。
- 新增长期玩法三步引导，可随时从教程页面重新查看。
- 登录云端时使用服务器时间校准每日刷新，并显示云端修订版本与同步状态。
- 主界面升级为动态舰桥风格，加入轨道星体、环境星空、扫描线、伪 3D 芯片和更清晰的信息层级。
- v0.3 及更早版本存档会自动补齐长期养成数据，云存档继续兼容。

## 如何试玩

在线访问上方 GitHub Pages 链接。也可以直接双击 `index.html` 进行基础试玩；PWA、离线缓存等功能需要通过 HTTPS 或本地服务器使用。

## 文件说明

- `index.html`：页面结构。
- `styles.css`：界面与动画。
- `core.js`：计分、协议识别与模块效果。
- `progression.js`：离线收益、远征、随机事件与科技树规则。
- `game.js`：游戏流程、教程、存档和交互反馈。
- `manifest.webmanifest`、`sw.js`：PWA 安装与离线缓存。
- `tests/core.test.js`、`tests/progression.test.js`：核心规则与长期养成自动测试。

当前仍是玩法验证版本，不包含付费或正式美术资源。云存档只保护账号归属和同步冲突；在加入挂机资源前，还需要把重要货币结算迁移到服务端函数。

## 云存档部署

1. 创建Supabase项目，在SQL Editor执行 `schema.sql`。
2. 在Authentication的URL设置中加入正式地址 `https://flowerbud0.github.io/infinite-protocol/`。
3. 从项目设置复制Project URL和publishable/anon key，填入 `cloud-config.js`。
4. 只可在网页端使用publishable/anon key，绝不能提交service_role key。
