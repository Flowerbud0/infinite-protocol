# 无限协议 v0.2

一款手机竖屏优先、同时兼容电脑浏览器的数字卡牌原型。

在线试玩：<https://flowerbud0.github.io/infinite-protocol/>

## v0.2 更新

- “转生”更名为“核心迭代”，并重新解释源代码、局内模块等术语。
- 计分公式使用与界面一致的精确值，逐项显示已触发的模块。
- 新增低位、奇数、三元、级联与融合流派模块。
- 永久迭代增益扩展为协议解锁、性能调校、资源效率、运行工具与启动配置五类。
- 加入可跳过、可重玩的互动教程，并引导第一次永久升级。
- 加入出牌分数、超频、换牌、过关、升级、核心迭代等反馈动画与轻量音效。
- 自动保存当前对局，提供主存档和冗余备份，并可使用存档码导入导出。
- 支持 PWA 安装和离线游玩。

## 如何试玩

在线访问上方 GitHub Pages 链接。也可以直接双击 `index.html` 进行基础试玩；PWA、离线缓存等功能需要通过 HTTPS 或本地服务器使用。

## 文件说明

- `index.html`：页面结构。
- `styles.css`：界面与动画。
- `core.js`：计分、协议识别与模块效果。
- `game.js`：游戏流程、教程、存档和交互反馈。
- `manifest.webmanifest`、`sw.js`：PWA 安装与离线缓存。
- `tests/core.test.js`：核心规则自动测试。

当前仍是玩法验证版本，不包含账号、云端同步、付费或正式美术资源。
