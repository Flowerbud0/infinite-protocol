# 无限协议 v0.1

一个手机竖屏优先、同时兼容电脑浏览器的数字卡牌原型。

## 如何试玩

直接双击 `index.html`，使用 Chrome、Edge 或其他现代浏览器打开即可。无需安装依赖，也不需要启动服务器。

## 当前玩法

- 每层抽取 6 张数字芯片，选择最多 5 张执行协议。
- 每层有 3 次运算和 2 次重排机会。
- 相同数字触发同步，连续数字触发连续链。
- 同一手同时满足两类协议时进入超频。
- 突破后从模块、新芯片和芯片融合中三选一。
- 层级 3 起可以主动转生，并使用源代码购买永久升级。
- 存档保存在浏览器 `localStorage` 中。

## 文件说明

- `index.html`：页面结构。
- `styles.css`：界面与动画。
- `core.js`：计分、协议识别、关卡目标等纯规则。
- `game.js`：游戏流程、交互和存档。
- `tests/core.test.js`：核心规则测试，可使用 `node tests/core.test.js` 运行。

这是玩法验证版本，不包含账号、联网、付费、音效或正式美术资源。
